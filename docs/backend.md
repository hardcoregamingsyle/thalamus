# Backend (Convex)

## What is Convex?

Convex is a serverless backend platform that provides: real-time database, serverless functions (queries/mutations/actions), file storage, scheduled functions, and HTTP routes. All backend code lives in `src/convex/`.

Key concepts:
- **Queries** — Read-only, automatically subscribe UI to changes
- **Mutations** — Read-write transactions, deterministic (no network calls)
- **Actions** — Can do anything (API calls, network), but can't read/write DB directly (must call internal mutations/queries)
- **Internal functions** — Only callable from other backend functions, not from client
- **Scheduled functions** — Async background jobs triggered by mutations

## Database Schema (src/convex/schema.ts)

50 tables are defined here, plus the 6 spread in from `@convex-dev/auth`'s `authTables`. `schemaValidation` is `false` — legacy rows would otherwise block deploys, so the validator will not catch drift for you.

## Credit System (AgentBucks)

- The spendable balance is `users.dailyAgentBucks` + `users.purchasedAgentBucks` + `creditBatches` rows (90-day expiry, spent soonest-first). `users.agentBucksBalance` also exists but is **not** the spendable balance.
- Per-token cost is computed by `calcAgentBucksForTier` in `agentCore.ts`, branching on the provider prefix (`modal:` / `nim:` / `ollama:`). The `modelPricing` table is not consulted.
- Credits reset daily via cron at 18:30 UTC (midnight IST) to 10,000,000.
- Platform-wide spend is tracked via the `platformBudget` table through `admin.deductPlatformCost`, with an auto-disable when the remaining budget drops under $5.
- **Currently disabled.** `FREE_UNLIMITED = true` in `agentCore.ts` makes `sandboxHelpers.deductAgentBucks` a no-op, so no user balance moves. `deductPlatformCost` is still called on every model call, but its `PLATFORM_PRICING` map only holds Claude and Gemini names, so current provider model names price at 0 and `platformBudget` does not accrue Thalamus spend.

## HTTP Routes (src/convex/http.ts)

| Method | Path | Purpose |
|--------|------|---------|
| POST / OPTIONS | `/stream-chat` | SSE streaming for chat/study modes |
| POST | `/github/webhook` | GitHub push events for auto-sync (no signature verification) |
| GET | `/github/callback` | OAuth code exchange → token storage |
| GET | `/auth/google`, `/auth/google/callback` | Google OAuth |
| GET | `/auth/github` | GitHub OAuth entry |
| POST | `/bmac/webhook` | Buy Me a Coffee payment webhook |
| POST / OPTIONS | `/api/v1/chat/completions` | OpenAI-compatible API for `thal_` keys |
| GET / OPTIONS | `/ad` | Sponsored-ad proxy |
| POST / OPTIONS | `/ao/v1/search`, `/ao/v1/answer`, `/ao/v1/learn` | AgentOverflow REST |
| GET / OPTIONS | `/ao/v1/learnings`, `/ao/v1/balance` | AgentOverflow REST |
| POST / OPTIONS / GET / DELETE | `/ao/mcp` | AgentOverflow MCP server |
| POST / OPTIONS / GET / DELETE | `/sketchfab/mcp` | Built-in Sketchfab 3D-model MCP server |
| GET / OPTIONS | `/ao/public/doc` | Crawlable doc payloads |
| GET | `/ao/sitemap.xml`, `/ao/sitemaps/*` | AgentOverflow sitemaps |

`auth.addHttpRoutes(http)` also registers the `@convex-dev/auth` `/api/auth/*` family, which no client uses.

The streaming endpoint (`/stream-chat`) implements full SigV4 signing for AWS Bedrock and parses the binary AWS event-stream protocol, falling back to Gemini and then VLY.

## Cron Jobs

Three jobs are registered in `crons.ts`:

| Job | Schedule | Calls |
|-----|----------|-------|
| reset daily agent bucks | `30 18 * * *` (18:30 UTC = 00:00 IST) | `internal.dailyReset.resetDailyAgentBucks` — resets every user's `dailyAgentBucks` to 10,000,000 |
| refill agentoverflow credits | `30 18 * * *` | `internal.agentoverflow.dailyRefillAoCredits` — decays contribution points ~1%/day, then tops balances up to the tier refill |
| sync agentoverflow keys to vm | every 2 minutes | `internal.agentoverflow.syncKeysToVm` — pushes the key-hash snapshot so the corpus VM can authorize search without calling Convex |
