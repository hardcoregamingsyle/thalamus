# Backend (Convex)

## What is Convex

Convex is a serverless backend platform: real-time database, serverless functions (queries / mutations / actions), file storage, scheduled functions, and HTTP routes. All backend code lives in `src/convex/`.

- **Query** — read-only, subscribes UI to changes.
- **Mutation** — read-write transaction, deterministic, no external calls.
- **Action** — arbitrary work (HTTP, network), but cannot read/write DB directly; must delegate to internal queries/mutations.
- **Internal function** — only callable from other backend functions.
- **Scheduled function** — background job kicked off via `ctx.scheduler`.

Current size: 312 exported functions across ~50 modules plus the `src/convex/lib/` helpers. `bun run check-refs` validates 605 references (27 of them from the sibling AgentOverflow repo).

## Database schema (`src/convex/schema.ts`)

`schemaValidation: false` — legacy rows would otherwise block deploys, so the validator does not catch drift for you. The schema mixes in `authTables` from `@convex-dev/auth/server` for legacy row compatibility; no live path uses those tables.

## HTTP routes (`src/convex/http.ts`)

| Method | Path | Purpose |
|---|---|---|
| POST / OPTIONS | `/stream-chat` | SSE streaming for chat / research / study / niche modes |
| POST | `/github/webhook` | GitHub push events for auto-sync — no signature verification |
| GET | `/github/callback` | OAuth code exchange → token storage |
| GET | `/auth/google`, `/auth/google/callback` | Google OAuth |
| GET | `/auth/github` | GitHub OAuth entry |
| POST | `/bmac/webhook` | Buy Me a Coffee payment webhook |
| POST / OPTIONS | `/api/v1/chat/completions` | OpenAI-compatible API for `thal_` keys |
| POST | `/code/command-result` | GitHub Actions worker → job result callback, one-time nonce |
| POST | `/code/vm-poll` | Worker poll for pending commands; heartbeat; keep-alive protocol (300s incomplete / 600s completed idle windows) |
| POST | `/code/sandbox-callback` | Sandbox tunnel URL callback, one-time nonce (per-dispatch, in the query string) |
| GET / OPTIONS | `/ad` | Sponsored-ad proxy |
| POST / OPTIONS | `/ao/v1/search`, `/ao/v1/answer`, `/ao/v1/learn` | AgentOverflow REST |
| GET / OPTIONS | `/ao/v1/learnings`, `/ao/v1/balance` | AgentOverflow REST |
| POST / OPTIONS / GET / DELETE | `/ao/mcp` | AgentOverflow MCP server |
| POST / OPTIONS / GET / DELETE | `/sketchfab/mcp` | Built-in Sketchfab MCP server |
| GET / OPTIONS | `/ao/public/doc` | Crawlable doc payloads for AO |
| GET | `/ao/sitemap.xml`, `/ao/sitemaps/*` | AgentOverflow sitemaps |

The three `/code/*` routes are unauthenticated by necessity — the GitHub Actions job runs on a public repo with no shared secret. Their single-use nonces (`vmNonce` on the branch, per-command nonces on `codeCommands`, per-dispatch nonces in the sandbox callback URL) carry the whole weight; an unknown or stale nonce is a silent 404 rather than a 401 (naming a valid nonce shape would be free reconnaissance). See [`executors.md`](./executors.md) for the full protocol.

The streaming endpoint (`/stream-chat`) implements full SigV4 signing for AWS Bedrock and parses the binary AWS event-stream protocol, falling back to Gemini and then VLY.

## Cron jobs (`src/convex/crons.ts`)

| Job | Schedule | Calls |
|---|---|---|
| reset daily agent bucks | `30 18 * * *` (18:30 UTC = 00:00 IST) | `internal.dailyReset.resetDailyAgentBucks` — resets every user's `dailyAgentBucks` to 10,000,000 |
| refill agentoverflow credits | `30 18 * * *` | `internal.agentoverflow.dailyRefillAoCredits` — decays contribution points ~1%/day, then tops balances up to the tier refill |
| sync agentoverflow keys to vm | every 2 minutes | `internal.agentoverflow.syncKeysToVm` — pushes the key-hash snapshot so the corpus VM can authorize search without calling Convex |
| sweep stalled code branches | every 5 minutes | `internal.codeBranches.sweepStalledBranches` — revives a branch Convex's 600s action limit killed mid-step (status `"running"`, nothing scheduled to resume it). Skips branches legitimately parked on a pending command or API-key request. `MAX_REVIVES = 2` before giving up and setting the branch `"idle"`. |
| sweep paused code branches | every 5 minutes | `internal.codeBranches.sweepPausedBranches` — a different stall class: re-invokes `runPipelineAction` for every `"paused"` branch so its own 15-minute (`STALE_COMMAND_MS`) pending-command staleness check actually gets a chance to run. Without this, a branch parked on a command that will never get a result (dead VM worker, crashed runner) only re-checks staleness when a user happens to send a new message *after* the 15-minute mark — every retry before that is silent, because `runPipelineAction`'s own gate just re-parks quietly. Safe on every legitimate "paused" case too (a live in-flight command, an open key request) — those just re-park again, harmlessly. |

## Credit system (AgentBucks)

- Spendable balance = `users.dailyAgentBucks` + `users.purchasedAgentBucks` + rows in `creditBatches` (90-day expiry, spent soonest-first). `users.agentBucksBalance` also exists but is **not** the spendable balance.
- Per-token cost is `calcAgentBucksForTier` in `src/convex/lib/agentCore.ts`, branching on the provider prefix (`modal:` / `zen:` / `deadlysignals:` / `modelscope:` / `ollama:`). Modal and Ollama compute a real number; every other prefix contributes 0.
- Daily reset: cron at 18:30 UTC (midnight IST) to 10,000,000 AB per user.
- Platform-wide spend is tracked via the `platformBudget` table through `admin.deductPlatformCost`, with auto-disable when the remaining budget drops under `BUDGET_THRESHOLD = 5.0`.
- **Currently disabled.** `FREE_UNLIMITED` in `src/convex/lib/agentCore.ts` is `true`, so `credits.deductAgentBucks` is a no-op. `deductPlatformCost` is still called on every model call; `calcPlatformCost` strips the provider prefix and returns 0 for any name not in `PLATFORM_PRICING`. `PLATFORM_PRICING` only knows `gemini-3.1-flash-lite`, `claude-haiku-4-5`, `claude-sonnet-4-6`, `claude-opus-4-6`, `claude-opus-4-8` — so Zen, DeadlySignal, ModelScope, Ollama, and every non-Claude/non-Gemini Modal model all contribute 0 by design (the current chain is free tiers). The budget guard cannot trip on Thalamus traffic while nothing costs anything.
